# 네이버 예약 취소표 자동 잡기 (회차 자동 선택 + 다음)

네이버지도 → 매장 → **예약하기** 화면에서

1. **목·금·토·일** 날짜를 차례로 눌러보고
2. 회차(오전 10:30, 오후 3:00 …) 중 **열린 자리**가 나오면 바로 눌러서 선택하고
3. 달력 아래 **`다음`** 버튼까지 눌러 다음 화면으로 넘긴 뒤
4. 소리(+선택: 텔레그램)로 알려주고 멈춥니다.

예약자 정보 입력과 최종 확정은 **직접** 하세요.

---

## 1. 설치 (처음 한 번)

1. 이 폴더(`naver-booking-watcher`)를 PC에 받습니다. GitHub에서 **Code → Download ZIP**을 누르고 압축을 풉니다.
2. 폴더 안의 **`install_windows.bat`을 더블클릭**합니다.
   - 파이썬이 없으면 다운로드 페이지가 열립니다. 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하고 설치한 뒤, 다시 더블클릭하세요.

직접 명령어로 설치할 때는 `pip` 대신 아래 명령을 쓰세요. (`pip`이 인식되지 않는 경우가 많습니다.)

```bash
py -m pip install playwright
```

## 2. 사용법

```bash
python watcher.py
```

(Windows에서는 `run_windows.bat`을 더블클릭해도 됩니다.)

1. 크롬 창이 뜨면 **네이버에 로그인**합니다. 로그인 정보는 `chrome-profile/` 폴더에 저장되므로 다음부터는 다시 할 필요가 없습니다.
2. 네이버지도에서 매장(예: 치이카와샵 용산점)을 열고 **예약하기** 탭에서 달력이 보이게 합니다.
3. 명령창으로 돌아와 **Enter**를 누르면 감시를 시작합니다.

```
[14:02:11] 감시 시작: 요일=목금토일, 간격≈15s
[14:02:19] #1 가능/전체 회차  11/5(목):0/22  11/6(금):0/22  11/7(토):0/22  11/8(일):0/22
...
[14:09:40] 🔔 [취소표 잡음] 11/7(토) 오후 3:00 회차 선택 + '다음' 클릭 완료! 브라우저에서 예약을 마무리하세요.
```

`0/22`는 "열린 회차 0개 / 전체 회차 22개"라는 뜻입니다.

### 처음에는 꼭 `--inspect`로 확인하세요

```bash
python watcher.py --inspect
```

달력 날짜, 매진 표시, 회차별 가능/불가 판정을 출력만 하고 끝납니다. 확인할 점:
- 날짜와 요일이 맞게 나오는지
- 매진된 회차가 모두 `✖ 불가`로 나오는지

이상하면 결과 파일 `inspect.json`을 보내주시면 맞춰 드립니다.

## 3. 옵션

| 옵션 | 설명 | 예시 |
|---|---|---|
| `--days` | 눌러볼 요일 (기본 `목금토일`) | `--days 토일` |
| `--dates` | 특정 날짜만 | `--dates 6,7,8` |
| `--until` | 이 날짜까지만 | `--until 2026-11-15` |
| `--times` | 원하는 회차만 (앞에 쓴 게 우선) | `--times "오후 3:00,오후 3:30"` |
| `--from` / `--to` | 이 시간대 회차만 | `--from 12:00 --to 18:00` |
| `--interval` | 한 바퀴 돈 뒤 쉬는 시간(초, 기본 15, 최소 5) | `--interval 20` |
| `--date-wait` | 날짜 누른 뒤 회차 로딩 기다리는 시간(초, 기본 1.2) | `--date-wait 2` |
| `--reload-every` | N바퀴마다 새로고침 (기본 10, 0이면 안 함) | `--reload-every 5` |
| `--no-next` | 회차만 고르고 `다음`은 누르지 않음 | |
| `--dry-run` | 아무것도 누르지 않고 알림만 | |
| `--max-minutes` | 최대 실행 시간(분) | `--max-minutes 120` |
| `--url` | 시작할 때 열 주소 | `--url "https://map.naver.com/p/entry/place/..."` |

예시: 토·일 오후 회차만 노리기

```bash
python watcher.py --days 토일 --from 12:00
```

### 이미 켜둔 크롬에 붙이기 (선택)

평소 쓰는 크롬과 별도로, 원격 디버깅 포트를 열어 크롬을 실행합니다.

```bash
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\chrome-macro"
```

그 창에서 로그인하고 예약 화면을 띄운 뒤 실행합니다.

```bash
python watcher.py --cdp http://127.0.0.1:9222
```

### 휴대폰 알림 (텔레그램, 선택)

환경변수 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 설정하면 자리를 잡았을 때 텔레그램으로도 알려줍니다.

```bash
set TELEGRAM_BOT_TOKEN=123456:ABC...
```

```bash
set TELEGRAM_CHAT_ID=987654321
```

## 4. 인식 방식

네이버는 클래스 이름을 자주 바꾸기 때문에, 이 매크로는 화면 구조를 보고 요소를 찾습니다.

- **달력**: `2026.11` 헤더와 `일 월 화 수 목 금 토` 요일 줄을 기준으로, 각 열에 있는 숫자(또는 `오늘`) 칸을 날짜로 봅니다. 네이버지도처럼 iframe 안에 있어도 찾습니다.
- **회차**: `오전/오후 h:mm` 글자가 있는 버튼을 회차로 봅니다.
- **불가 판정**: 아래 중 하나라도 해당하면 불가로 봅니다.
  - `disabled` 또는 `aria-disabled` 속성
  - 클래스 이름에 `unselectable`, `disabled`, `soldout` 등이 들어 있음
  - `매진`, `마감` 문구
  - 흐린 회색 글자 (`--no-color-check`로 끌 수 있음)
- **오인식 방지**: 회차를 누른 뒤 실제로 선택 상태가 됐는지 다시 확인합니다. 선택되지 않았으면 그 회차는 건너뜁니다.
- **다음 버튼**: 회차를 선택하면 회색이던 `다음` 버튼이 활성화됩니다. 활성화될 때까지(최대 6초) 기다렸다가 누릅니다.

## 5. 주의

- 간격을 너무 짧게 잡으면 네이버에서 일시 차단하거나 보안문자를 띄울 수 있습니다. 기본값 15초 정도를 권장합니다.
- 매크로 사용은 네이버 이용약관에 어긋날 수 있고, 매장 정책(1인 1매, 본인 입장)도 그대로 적용됩니다. 본인 예약 용도로만, 책임지고 사용하세요.
- 보안문자(캡차)는 자동으로 풀지 않습니다. 뜨면 직접 입력하세요.
- 현재 보이는 달(예: 2026.11)의 날짜만 확인합니다.

## 테스트용 모의 페이지

`tests/mock_map.html`은 실제 화면을 흉내 낸 페이지입니다(지도 안 iframe, 달력, 회차, 다음 버튼). 일정 시간이 지나면 토요일 오후 3:00에 취소표가 생깁니다.

```bash
python watcher.py --url "file:///<이 폴더 경로>/tests/mock_map.html?openAfter=10" --interval 5
```

`?mode=color`를 붙이면 불가 회차를 글자색으로만 구분하는 경우를 테스트합니다.
