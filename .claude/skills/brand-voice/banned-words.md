# 금칙어와 대체 표현

> 초안: 건강기능식품 표시·광고 규정과 브랜드 톤을 기준으로 작성했다. 사내 확정 목록이 있으면 이 표를 교체·보완할 것.

## 법규 위반 위험 (반드시 제거)

| 금칙어 | 이유 | 대체 표현 |
|---|---|---|
| 치료, 완치, 낫는다 | 질병 치료 효능 표방 금지 | 식약처 인정 기능성 문구 (예: "~에 도움을 줄 수 있음") |
| 예방, 막아준다 (질병 대상) | 질병 예방 효능 표방 금지 | "정상적인 면역기능에 필요" 등 인정 문구 |
| 특효, 만병통치 | 과장·질병 효능 암시 | 삭제. 해당 원료의 인정 기능성 문구로 대체 |
| 해독, 디톡스, 독소 배출 | 인정되지 않은 기능 | 삭제 |
| 부작용 없음, 무해, 100% 안전 | 안전성 단정 불가 | "섭취 시 주의사항을 확인하세요" |
| 의사 추천, 전문의 처방, ○○병원 사용 | 전문가 추천·보증 광고 제한 | 시험기관·측정 방법 등 객관적 근거 제시 |
| 즉시, 바로 효과, 먹는 순간 | 효능 시기 단정 | 삭제. 1일 섭취량·섭취 방법 안내 |
| ○kg 감량, 살이 빠진다 | 체험·효능 단정 | "체지방 감소에 도움을 줄 수 있음" (인정 원료에 한함) |

## 브랜드 톤 위반 (대체할 것)

| 금칙어 | 이유 | 대체 표현 |
|---|---|---|
| 최고, 최초, 1위, 유일 | 근거 없는 최상급 | 측정값 + 기준 (예: "1일 섭취량 기준 500mg") |
| 100%, 완벽 | 절대 표현 | 측정 수치와 오차 범위, 시험기관명 |
| 고함량, 고농축 | 수치 없는 주장 | "○○ 1일 섭취량 기준 ○mg" |
| 프리미엄, 고품질, 좋은 성분 | 막연한 형용사 | "정확한 함량", 원료명·원산지·시험 결과 |
| 믿어주세요, 믿고 드세요 | 신뢰 호소 | "기록을 보여드립니다", "시험성적서를 공개합니다" |
| 기적, 놀라운, 혁신적인 | 감탄·과장 | 삭제. 사실 한 문장으로 대체 |
| 대박, 꿀템, 강추, 끝판왕 | 속어 | 삭제. 측정 사실로 대체 |
| 천연이라 안전 | 천연 ≠ 안전, 논리 비약 | 원료 원산지와 시험 결과 제시 |
| 건기식 (제품 설명·법적 고지에서) | 정식 명칭 아님 | 건강기능식품 |

## 표기 규칙

| 항목 | 규칙 | 예시 |
|---|---|---|
| 함량 | 아라비아 숫자 + 단위 붙여쓰기, 천 단위 쉼표 | 500mg, 25μg, 1,000IU |
| 기준 | 함량에는 기준을 함께 표기 | 1일 섭취량(2정) 기준 |
| 원료명 | 성분표 표기와 동일하게 | 비타민 D, 아연, EPA 및 DHA 함유 유지 |
| 기능성 | 식약처 인정 문구를 그대로 | "뼈의 형성과 유지에 필요" |
| 고지 | 상세페이지·광고에 섭취 시 주의사항 포함 | — |
| 문장부호 | 느낌표·이모지 사용하지 않음 | — |
