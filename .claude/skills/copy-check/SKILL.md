# 카피 검수

검수 대상: $ARGUMENTS

## 절차

1. **대상 확인.** `$ARGUMENTS`가 파일 경로면 그 파일을 읽고, 아니면 붙여넣은 문장 자체를 검수 대상으로 삼는다. 비어 있으면 검수할 카피를 요청한다.
2. **기준 읽기.** 아래 두 파일을 읽는다.
   - `.claude/skills/brand-voice/SKILL.md` — 반드시 지킬 것 / 절대 쓰지 않는 것 / 표기 규칙
   - `.claude/skills/brand-voice/banned-words.md` — 금칙어와 대체 표현
   - 톤 판단이 애매하면 `.claude/skills/brand-voice/examples.md`의 좋은 예·나쁜 예와 비교한다.
3. **대조.** 문장 단위로 금칙어, 법규 위반 위험 표현, 근거 없는 주장, 표기 규칙, 톤(짧고 단정한가, 주장 대신 측정값인가)을 점검한다.
4. **결과 제시.**

## 출력 형식

문제가 있으면 표로 제시한다.

| 문제 문장 | 위반 규칙 | 수정안 |
|---|---|---|
| 원문 그대로 인용 | 어떤 규칙인지 (예: 금칙어 "최고" — 근거 없는 최상급) | 브랜드 톤에 맞춘 수정 문장 |

- 법규 위반 위험(질병 예방·치료 등)은 표 위에 별도로 먼저 알린다.
- 수정안에 필요한 수치를 알 수 없으면 `○○mg`처럼 자리표시를 두고 확인이 필요하다고 적는다.

문제가 없으면 "검수 결과 위반 사항이 없습니다."라고 말한다.

## 지켜야 할 것

- **원본 파일은 절대 수정하지 않는다.** 수정안만 제시한다.
- 규칙에 없는 개인 취향으로 지적하지 않는다. 모든 지적은 brand-voice 규칙이나 banned-words.md의 항목에 근거한다.
