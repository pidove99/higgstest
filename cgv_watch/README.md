# CGV 회차 오픈 알림

CGV 상영시간표 페이지를 몇 분마다 확인하다가 원하는 영화의 회차가 올라오면 **PC 알림, 소리, 브라우저 열기**로 알려줍니다.
**예매와 결제는 하지 않습니다.** 알림이 오면 직접 예매하세요.

## 설치 (처음 한 번)

```bash
pip install playwright plyer
python -m playwright install chromium
```

`plyer`는 PC 알림용입니다. 설치하지 않아도 소리 알림은 동작합니다.

## 사용법

1. 평소 쓰는 브라우저로 CGV에 접속해 **원하는 극장과 날짜의 상영시간표 화면**으로 이동한 뒤 주소창 URL을 복사합니다.
2. 페이지에서 영화 제목이 어떻게 읽히는지 먼저 확인합니다.
   ```bash
   python cgv_watch.py --url "복사한URL" --dump
   ```
   `page_dump.txt`를 열어 영화 제목과 상영시각이 보이는지 확인하세요.
   아무것도 보이지 않으면 `--headed`를 붙여 다시 시도합니다.
3. 감시를 시작합니다.
   ```bash
   python cgv_watch.py --url "복사한URL" --movie "영화제목"
   ```

### 예시

```bash
# IMAX 회차가 열리면 알림
python cgv_watch.py --url "..." --movie "영화제목" --must "IMAX"

# 무대인사 회차, 2분 간격
python cgv_watch.py --url "..." --movie "영화제목" --must "무대인사" --interval 120
```

## 옵션

| 옵션 | 설명 |
|---|---|
| `--movie` | 찾을 영화 제목. 페이지에 표시되는 그대로의 일부를 넣습니다. |
| `--must` | 함께 있어야 하는 키워드(IMAX, 4DX, 무대인사 등). 여러 번 쓸 수 있습니다. |
| `--interval` | 확인 간격(초). 기본 180초, 최소 60초입니다. |
| `--headed` | 브라우저 창을 띄워서 확인합니다. 화면이 안 읽힐 때 사용합니다. |
| `--keep` | 발견한 뒤에도 계속 감시합니다. |
| `--no-time-check` | 제목 바로 뒤에 상영시각(HH:MM)이 있는지 확인하지 않습니다. |
| `--no-open` | 발견해도 브라우저를 열지 않습니다. |
| `--dump` | 한 번만 읽어서 페이지 텍스트를 `page_dump.txt`로 저장합니다. |

## 참고

- 사이트에 부담을 주지 않도록 확인 간격은 최소 60초이고, 매번 약간의 무작위 지연이 붙습니다.
- 배너에 제목만 있는 경우 오탐하지 않도록, 기본적으로 **제목 바로 뒤에 상영시각이 있어야** 발견으로 판단합니다.
- CGV 화면 구성이 바뀌면 `--dump`로 텍스트를 다시 확인하고 `--movie`/`--must` 값을 조정하세요.
- 컴퓨터가 절전 모드에 들어가면 감시가 멈춥니다.
